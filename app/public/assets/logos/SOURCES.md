- Terms: Anthropic trademarks. Press-kit artwork used unmodified. See also Anthropic’s trademark guidelines (`https://assets.claude.com/f7874b435aabdaee5f836e888b4439b9b56a934b.pdf`) and `https://www.anthropic.com/legal`.

## vscode.svg

- Source: Official Visual Studio Code icons ZIP from `https://code.visualstudio.com/brand` (`https://code.visualstudio.com/assets/branding/visual-studio-code-icons.zip`), file `visual-studio-code-icons/vscode.svg`, plus the archive `README.txt`.

- Terms: Visual Studio Code, VS Code, and the icon are trademarks of Microsoft Corporation. Guidelines: `https://code.visualstudio.com/brand`. Microsoft permits the icon in documentation or a tutorial about Visual Studio Code. This site uses a modest 32px icon next to the product name to identify the client in a connect guide, not as a designed brand lock-up, and not to promote Unwhelm as a Microsoft product. The artwork is unmodified.

- Asset: official Gemini sparkle with its published gradient, unmodified.
- Terms: Gemini and the mark are trademarks of Google LLC. See Google’s Brand Resource Center guidance at `https://about.google/brand-resource-center/guidance/`. Used only to identify Gemini CLI / Gemini, unmodified, without implying endorsement. Google does not currently publish a separate official Gemini press-kit SVG on the Brand Resource Center product list, so this official product artwork from Google’s CDN is the source.

## codex.svg

- Source: Official OpenAI logo package from `https://openai.com/brand/`, ZIP `https://cdn.openai.com/brand/OpenAI-Logos-2025.zip`, file `OpenAI-logos(new)/SVGs/OpenAI-black-monoblossom.svg`.
