What is being mapped?

MCP tools are API operations, not database tables. Tools call the backend API; the backend handles persistence and authorization. The tree groups tools by business entity, while the diagram uses model names from prisma/schema.prisma.

Permission model

There are 100 named tools in the source. Of these, 91 have a required scope listed in unwh-mcp/src/toolAccess.ts. Nine are not scope-filtered at the MCP tool-listing layer; staff and admin checks may still hide tools; that does not mean every underlying API operation is anonymous or unrestricted. An admin scope satisfies all named scope checks; staff membership and workflow rules may impose additional restrictions.

The client demo described in the site screenshot surfaced 64 listed / 24 hidden for its particular token. Actual visibility depends on the token's grants; it is not an intrinsic property of a tool.
